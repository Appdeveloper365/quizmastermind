Privacy Policy

App: Quiz Mastermind — an AI trivia quiz that runs entirely in your browser.

Last updated: October 8, 2026

Short version: Quiz Mastermind has no accounts, no analytics and no server of its own. Your quiz data, preferences and API keys stay on your device. When you generate a question, a short prompt is sent to the AI provider you selected — using your key or your account — and that provider's own privacy policy applies to it. Pick the local or in-browser AI and nothing is sent anywhere.

1. What this app is

Quiz Mastermind is a static website (a progressive web app) served from GitHub Pages. It is built as plain HTML/CSS/JavaScript — there is no Quiz Mastermind database, login system or backend. Everything the app “remembers” is written to your own browser.

2. What is stored (only on your device)

  • API keys — if you paste your own key (Google Gemini, Groq, Pollinations, OpenRouter or xAI), it is saved in your browser's localStorage under names like quiz.key.gemini. It is encoded (base64), not encrypted — the protection is that it lives only in your browser profile on this device. It is shown masked and locked in the app, and never sent anywhere except to that provider's API when you generate a question. Remove it with “🗑 Clear this key”, or wipe it entirely by clearing this site's data.
  • Quiz data — score, high score, streaks, accuracy (quiz.stats) and your recent answers (quiz.recent, up to 8) in localStorage.
  • Question history — the text of questions you've already been asked, so they never repeat: stored per topic+difficulty in IndexedDB (database quiz-mastermind, capped at 500 per topic). Removed by “🔄 Forget what I've seen…”.
  • Preferences — topic, difficulty, provider choice, auto-advance and reuse settings.
  • App files & AI model — a service worker caches the app itself so it opens offline, and if you enable in-browser AI the model weights (roughly 500 MB–1.8 GB) are cached in your browser's Cache Storage. Both are removed by clearing this site's data.

Clearing your browser/site data, or using the in-app “Clear this key”, “Forget what I've seen…” and “Clear list” controls, removes the corresponding data permanently. Because there is no server, there is nothing we can delete for you — the data never reached us.

3. What leaves your device (only when you generate a question)

Your chosen provider receives: the topic you typed, the difficulty, a system prompt, a rotating random “angle” hint, and — for cloud providers only — the text of up to 60 previously asked questions so they don't repeat. Requests go straight from your browser to the provider; they never pass through a Quiz Mastermind server (there isn't one).

  • Google Gemini (generativelanguage.googleapis.com) — policies.google.com/privacy
  • Groq (api.groq.com) — groq.com/privacy-policy
  • Pollinations (gen.pollinations.ai) — pollinations.ai/terms
  • OpenRouter (openrouter.ai) — openrouter.ai/privacy
  • xAI (api.x.ai) — x.ai/legal/privacy-policy
  • Puter (optional) — AI runs under your Puter account in Puter's “user-pays” model. Using it loads Puter's own script from js.puter.com on demand (only when you pick Puter) and sends your prompts to Puter's API; Puter sets its own session storage/cookies under its policy: puter.com/privacy.
  • Ollama / LM Studio (optional) — requests go to http://localhost on your own machine. Nothing leaves your device or network.
  • In-browser AI (WebLLM) (optional) — the model itself is downloaded once from the public Hugging Face model repository (huggingface.co, operated by Hugging Face, Inc.) and cached locally; those hosts see your IP during that download. After that, questions are generated entirely on your device — your topics and questions never leave it.

Hosting: the site's files are served by GitHub Pages, so GitHub processes routine connection data (IP address, user agent, time) as your host: GitHub privacy statement.

4. What we do NOT do

  • No accounts or sign-ups on this site (signing in to Puter is an account with Puter, not with us).
  • No analytics, tracking, advertising, profiling or cookies set by us.
  • No access to your contacts, files, camera, microphone or location — the app never requests those permissions.
  • No selling, sharing or analytics on your data — we don't receive it in the first place.
Honest note about API keys: keys you paste are stored obfuscated, not encrypted, inside your browser profile. Anyone with access to this device and browser profile — or malicious code running on this page — could read them. Don't save a key on a shared or public computer; use “🗑 Clear this key” when you're done. The app runs a strict Content-Security-Policy so only the code listed in index.html (and the AI providers above) can run and be contacted.

5. Children

The app is a general-audience quiz. It is not directed at children under 13. Questions are written to a “suitable for all ages” instruction, but the text is generated by AI: it can be inaccurate or occasionally unsuitable, so a parent/guardian should supervise younger users. We knowingly collect no personal data from anyone, including children — because we collect nothing.

6. Your rights

Because all app data lives in your browser and the prompts go to third-party AI providers under their policies, you control it directly: use the in-app clear controls, clear this site's data in your browser, and use each provider's own account/data tools if you want to act there. Requests or questions about this policy: open an issue (link below).

7. Changes

If this policy changes, the “Last updated” date at the top changes with it. Material changes will be announced in the repository's release notes.

8. Contact

Questions or requests: open an issue at github.com/appdeveloper365/quizmastermind/issues.
